# TRIKI Arcade (Android)
Minigry sterowane nasadką Triki. Wrapper Capacitor + natywny Bluetooth LE.
Budowanie APK: wrzuć repo na GitHub -> zakładka Actions -> "Build APK" -> Run workflow -> pobierz artefakt TRIKI-Arcade-apk.
Folder .github/workflows/build.yml musi być w repo (jeśli upload go pominął, utwórz plik ręcznie w GitHubie).
